# W1 — frontend, UX and design system

**Method.**
- A scripted sweep (`sweep.spec.ts` in the session scratchpad) ran with the repo's own Playwright and `@axe-core/playwright` against a **production build** of the app in demo mode. It covered 43 routes (all 33 org pages including detail pages, plus 10 public and auth pages) × light and dark × desktop (Desktop Chrome) and mobile (Pixel 7): **172 page loads**. It recorded HTTP status, console errors, stuck "Loading…" states, horizontal overflow, load time and axe results.
- A hand walk in the built-in browser covered the Command Center, Inbox (desktop and 375 px), the opportunity detail page, "Hunt now" in demo, and the keyboard entry path.
- A static read covered token use and dialogs.

Demo mode renders fixtures. This proves the UI layer only, not the data behind it.

## Sweep results

| Check | Result |
|---|---|
| Status | 200 on every route except `/compare/` and the deliberate `/no-such-page` (both 404, with a branded not-found page) |
| Stuck loading | none: every route rendered past its skeleton |
| Horizontal overflow at 375 px | **none** on any route, in either theme |
| Console errors | none, apart from the two expected 404s |
| Load time | every route under 2 s on the local production build (networkidle) |
| Accessibility | 3 rule types on 4 routes (see `02_A11Y.md`) |

## Hand walk

| Area | Observation | Verdict |

## Findings

### [Low] TRUST-301: Model-written "why now" prose can carry relative time ("three days ago") that goes stale while the page shows no date for when it was written
- Confidence: LIKELY. The demo shows the effect: the Why-now inference says "The Series A closed three days ago" directly above evidence marked "3 months ago · STALE", and the dashboard card repeats "a trigger 3 days ago". `explain_why_now` asks for a horizon rather than a date (`packages/ai/src/tasks/explain-why-now.ts:125`) but does not forbid relative time in its prose. Inference blocks render no generation timestamp. Not seen with a live model.
- Impact: a stale inference reads as current. This is a quieter version of "unsourced claim on a decision surface", partly mitigated by the STALE badges on the evidence beside it.
- Fix: tell the task (and `qualify_opportunity`) to write absolute dates or none, and render "written on <date>" on every inference block. Fix the demo fixture's "three days ago".
- Effort: S · Mechanizable: partly (a `verify-tasks` check that output contains no "N days ago") · Status: New

### [Info] UX-301: `/compare` has no index page
- A user trimming `/compare/ai-sdr` to `/compare` gets the 404 page. Add an index or redirect to `/`.

## Not covered by this pass
- **Real-data states.** Empty, error and partial states with a live database. Demo fixtures always have data, so empty states were seen only where the fixture is empty.
- **Visual design quality judgement** across all 54 pages. This pass sampled the core surfaces; `audit/UX-REVIEW.md` is the last full design review.
- **Onboarding (`/welcome/*`)** past its first screen: it requires a session in the production build (the sweep saw the sign-in redirect).
